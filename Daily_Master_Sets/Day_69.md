# RC 1 — THE VALUE OF PRECISION

### Passage

Precision is often treated as the enemy of ambiguity. In scientific and administrative settings, a precisely defined category appears to offer a clear advantage: different observers can apply the same rule and, ideally, arrive at the same result. Yet precision does not eliminate judgment; it merely relocates it. Before a category can be applied consistently, someone must decide which distinctions matter and which differences can be ignored.

This becomes particularly important when categories are used outside the environment in which they were designed. A classification system developed for a narrow purpose may become an administrative standard for a much wider population. Its apparent objectivity can then conceal assumptions that were never intended to govern the new cases. The problem is not that categories are artificial. Every useful classification necessarily simplifies reality. The problem arises when the simplification is forgotten.

Consequently, better classification does not necessarily mean creating ever more detailed categories. Excessive refinement can make a system difficult to use while giving its users an exaggerated sense of certainty. A useful classification is one whose distinctions correspond sufficiently well to the purpose for which it is being used.

Precision, then, should not be understood as the elimination of ambiguity at all costs. It is better understood as disciplined simplification: deciding which uncertainty matters, which can be tolerated, and which must remain visible.

# RC 2 — TECHNOLOGY AND MEMORY

### Passage

Digital technology has transformed not only how information is stored but also how people relate to remembering. The availability of searchable records can reduce the practical need to retain certain facts internally. This is sometimes interpreted as evidence that technology weakens memory. Such a conclusion, however, assumes that the primary purpose of memory is to preserve information in isolation.

Human memory has never functioned simply as a storage device. Remembering involves selecting, organising and connecting information to existing knowledge. External records can therefore alter what people remember without necessarily diminishing the cognitive importance of memory. A person who relies on notes may remember fewer dates yet possess a better system for retrieving information when needed.

The more significant concern is not that external storage exists, but that dependence on it can affect the formation of knowledge. If information is always experienced as something that can be retrieved later, individuals may invest less effort in understanding relationships among facts. Retrieval is not equivalent to understanding, and an archive cannot automatically supply the conceptual structure through which information becomes meaningful.

The question, therefore, is not whether technology makes memory weaker in some narrow sense. It is whether the changing balance between internal memory and external storage supports or undermines the deeper cognitive functions that memory performs.
